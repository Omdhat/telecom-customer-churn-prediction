# Telecom Customer Churn Prediction

## Project Overview
A machine learning project that predicts whether a customer
is likely to churn.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit

## Machine Learning
- Data preprocessing
- Missing value handling
- Categorical encoding
- Train-test split
- Feature scaling
- Model training
- Hyperparameter tuning
- Model evaluation

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
